# **App Name**: Redação AI Pro

## Core Features:

- Study Chapters: A structured learning path with chapters covering all aspects of ENEM essay writing.
- Bonus Content: Additional resources, tips, and tricks for ENEM essay success.
- Essay Submission: Users can upload their essays for AI analysis.
- AI Essay Correction: The AI provides a grade based on ENEM criteria, along with detailed feedback on areas for improvement, acting as a helpful tool.

## Style Guidelines:

- Primary color: Vibrant orange (#FF7F50) to evoke creativity and energy, fitting for an educational app.
- Background color: Light peach (#FAEBD7), a desaturated version of orange, to provide a soft and welcoming backdrop.
- Accent color: Warm yellow (#FFD700) to highlight key elements and calls to action, drawing attention effectively.
- Font pairing: 'Literata' (serif) for headers to create an elegant, intellectual, literary feel and 'PT Sans' (sans-serif) for body text, offering readability and a modern touch.
- Use clear and consistent icons for chapter navigation and feature access.
- Clean, organized layout with clear sections for study materials, bonus content, and essay submission.
- Subtle transitions and animations to enhance user engagement and provide feedback during essay analysis.
